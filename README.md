Courier Delivery Route and Tracking System
A simple Java-based console application that manages courier details, calculates delivery charges based on distance, and tracks delivery status.
Project Overview
The Courier Delivery Route and Tracking System is a beginner-friendly Java mini project designed to organize basic courier information. It collects sender and receiver details, source and destination locations, and delivery distance. The application calculates the delivery charge automatically and displays the courier's tracking details.
Objectives
- Store courier and tracking information.
- Record sender and receiver details.
- Manage source and destination locations.
- Calculate delivery charges based on distance.
- Update the delivery status.
- Display complete courier tracking details.
